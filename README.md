# location-simulator

基于 [GoGoGo](https://github.com/ZCShou/GoGoGo) 公开的 1.12.3 代码二次开发。原项目说明见 [UPSTREAM_README.md](UPSTREAM_README.md)，项目依照 [GPL-3.0-only](LICENSE) 提供。

## 主要功能

- 使用 MapLibre Native 地图引擎和 OpenFreeMap 底图，不需要百度地图 Key；地图数据来自 [OpenStreetMap 及其贡献者](https://www.openstreetmap.org/copyright)。
- 地点搜索使用 Photon 公共服务：点击“搜索”输入地点，选中结果后在地图上查看。
- 点击地图选点，选择“收藏”保存名称；从收藏夹点击可请求传送，长按可删除。会尝试转换导入之前版本的收藏。
- 点击“画路线”，在地图上按顺序点选节点，再点击“保存路线”；从路线列表可载入或长按删除。点击“开始路线”输入米/秒速度，位置模拟由前台服务沿直线逐段回放，到达终点后保持该位置。通知栏或“停止模拟”可停止。
- 在模拟已启动后，可通过“悬浮摇杆”打开方向按钮；点击方向会停止路线回放并按步长移动。需要悬浮窗权限。
- “更新”按钮打开本仓库发行页，不再弹出原项目的更新。

## 使用说明

在系统开发者选项的“选择模拟位置信息应用”中选择本应用，才能启动模拟；悬浮控制还需手动授予悬浮窗权限。不同系统与目标应用对模拟位置的支持可能不同。

在线底图和搜索需网络；公共服务可能限制访问或不可用，国内地点数据覆盖和准确性因地区而异。位置与路线收藏保存在本机，卸载应用前请注意备份。地图点位与路线使用 WGS-84 坐标，旧收藏转换可能有误差。

此版本包含较大地图重构，应先在目标手机上测试地图、搜索、位置权限与后台回放；原版本的一些界面和功能尚未迁移，尤其是旧设置和历史记录页面。当前 APK 是测试用途，并非声称已完成真机验证。

## 构建

使用 JDK 17 与 Android SDK 编译。当前仓库仍保留原版代码，编译时需要在 `local.properties` 中给旧代码用的 `MAPS_API_KEY` 和 `MAPS_SAFE_CODE` 设置任意非空占位值；新地图页面不使用这些值。
