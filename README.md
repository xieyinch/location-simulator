# 位置模拟

基于 [GoGoGo / 影梭](https://github.com/ZCShou/GoGoGo) 1.12.3 的标准 Mock Provider 定位实现，参考 [Lecheeel/Portal](https://github.com/Lecheeel/Portal) 的高德地图、地点搜索、逐点／手绘路线和步行规划交互进行二次开发。项目以 GPL-3.0 发布，Portal 的 Apache-2.0 许可副本位于 `third_party/portal/LICENSE`。

## 功能

- 高德地图选点、地点搜索；坐标在高德 GCJ-02 与设备 WGS-84 之间转换。
- 收藏位置；逐点绘制或手绘路线；按首尾节点规划步行道路；路线保存和按速度模拟回放。
- 使用影梭 1.12.3 的 GPS / NETWORK 模拟位置发布方式，支持圆形悬浮摇杆、路线回放、定位状态与停止操作。
- 更新入口指向本项目发行页；Android 构建通过 GitHub Actions 生成 APK。

## 高德地图配置

高德地图 SDK 的 Key 必须绑定本 App 的包名和签名 SHA-1。首次进入应用可在弹窗填写自己的 Android Key；“设置 → 配置高德地图 Key”也可以修改。填写后须同意高德的隐私说明才会初始化 SDK。请在高德控制台为 Key 开通对应的地图、地点搜索和步行路线服务。没有 Key 时仍可在设置中手动输入 WGS-84 坐标并模拟位置，但地图、搜索和道路规划不可用。

也可在仓库 Actions Secret 中配置 `AMAP_ANDROID_KEY` 供构建注入。SDK Key 随 APK 可被提取，请自行配置平台侧包名／签名限制。模拟位置需要在系统开发者选项中选择本应用；悬浮方向控制需要悬浮窗权限。

本应用包名为 `io.github.xieyinch.locationsimulator`，与原影梭及早期测试版是不同应用，可并存；系统不能自动跨包读取旧版收藏或路线，旧应用数据不会自动迁移。公开原项目的签名配置仅用于测试构建，并非可保密的正式发布密钥。

地图、搜索和路线规划依赖高德 SDK、账号授权、网络与服务配额；坐标转换与模拟定位效果应在目标设备上验证，无法保证所有手机和目标应用兼容。原版部分设置、历史记录及 Portal 的其他功能尚未移植。

模拟定位开始后，界面显示系统接收状态；圆形摇杆松手停止，顶部可拖动或点击隐藏。系统接收不代表所有应用都会采用该位置。覆盖安装相同包名和签名的版本可保留本应用设置及收藏。
